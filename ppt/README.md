# `ppt/` - everything needed to build the SIH 2026 submission deck

Six slides, for **Problem Statement 26067** (MoES / INCOIS), theme **Disaster Management**,
category **Software**, team **Sigmoid**.

Nothing in this folder is a draft of the deck. It is the four things a person needs to *build*
one and be unable to get a fact wrong while doing it: the words, the look, the pictures, and the
numbers.

## The pictures

**`ppt/images/` is an output.** Nothing in it is edited, and a change made here is lost the next
time anybody publishes.

Two kinds of picture live in it, and they are made in two different ways.

### The nine boards - `S*.png`

Drawn as HTML in [`../scripts/ppt_diagrams.html`](../scripts/ppt_diagrams.html) and rendered
through a real browser at 2x:

```bash
cd web && node render-diagrams.mjs
```

**They are rendered rather than generated by an image model for one reason: every label in them
is a fact.** An image model cannot spell `incois_argo_10d_VAM`, cannot be trusted to put a
temperature in the box that is about temperature, and will happily draw an arrow from the wrong
node. A diagram with a wrong label in it is worse than no diagram, because it tells a judge that
nobody checked.

`S3-architecture.png` is also what README section 5 shows. One drawing of this system, in both
documents, because two drawings drift apart and nothing notices.

### The sixteen screenshots - `S*.jpg` and `spare-*.jpg`

**The one copy of every screenshot in this project lives in `assets/screenshots/light/` and
`assets/screenshots/dark/`**, named by what the picture shows. This folder is filled from there:

```bash
cd web && node capture.mjs --publish-only --publish
```

That opens no browser, takes about a second, and prints the date of every file it copies. It also
fills `docs/images/` for the README and `web/public/images/` for the landing page, so the three
documents cannot end up showing three different builds.

Everything here is **light theme**, because the SIH template is a white page and a dark
screenshot on it reads as a hole. `spare-kiosk.jpg` is the one exception: an exhibition screen is
a dark screen wherever it stands.

To replace one, grab the frame from a real browser and normalise it:

```bash
../.venv/Scripts/python scripts/normalise_screenshot.py <file.png> light <name>
cd web && node capture.mjs --publish-only --publish
```

**Never retouch a screenshot.** Not the numbers, not the colours, not to hide a control you do
not like. Cropping the browser chrome away is fine; cropping a value away is not. These are the
deck's proof, and they are the one class of asset in it that cannot be regenerated if doubted.

## The numbers

`FACTS.md` is written by [`../pipeline/scripts/collect_facts.py`](../pipeline/scripts/collect_facts.py):

```bash
cd pipeline && ../.venv/Scripts/python scripts/collect_facts.py
```

Run it after a bake and **diff the file**. A figure that moved shows up as a line, and then a
person decides what the sentence around it should now say - which is why this does not edit the
deck itself. A figure moving sometimes means a claim has to be rewritten rather than a digit
swapped.

Every row names where its figure came from, so a judge's question is answered by opening a file
rather than by remembering.

**This exists because the deck has been wrong twice.** Once it claimed 246 tests against a suite
of 377. Once it said the model read a float "1.64 °C cool" when the residual is negative and the
app's own panel, in the screenshot on the same slide, said warmer. Both were figures typed into
prose by hand, and nothing in the repository could check either.

## Before you upload

The full list is `DESIGN-SPEC.md` section 12. The four that actually get decks rejected:

- **Exactly six slides.** Never seven.
- **The five mandated section headings, word for word**, unchanged from the template.
- **No paragraph on a content slide.** Points, boxes, diagrams and images only.
- **Nothing overlapping the template's header or footer band.**

And the one blank: **Team ID**. It is `<FILL IN>` in `DECK.md` and it is the only thing in this
folder nobody has filled in. Leave it visible until you have it. Do not invent one.
