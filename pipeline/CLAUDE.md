# `pipeline/` - Python. Reads the data, does the science. All tested logic is here.

See the root [`CLAUDE.md`](../CLAUDE.md) for the rules that govern this code, and
[`CONTEXT.md`](../CONTEXT.md) for the vocabulary.

| File | What it does |
| --- | --- |
| `samudra/bake.py` | Orchestrator. Fetches, derives, warps, encodes, writes everything the browser and API consume. The `main()` CLI is `python -m samudra.bake`. |
| `samudra/sources/base.py` | **The extensibility seam.** `BoundingBox`, `FieldSpec`, `Profile`, and the `GridSource` / `ProfileSource` protocols. A new provider implements one of these and nothing else changes. |
| `samudra/sources/incois.py` | INCOIS ERDDAP adapters, **two datasets one class shape**. `IncoisErddapSource` is the VAM analysis - gridded temperature and salinity, `incois_argo_10d_VAM`. `IncoisMcCrearySource` is `incois_argo_10day_McCreary`: a second independent analysis of the same Argo floats on exactly the same grid, carrying INCOIS's own observation count and their own RMSE. |
| `samudra/sources/argo.py` | Argo adapters. `ProfileColumns` makes the column layout data rather than code, and `measurements` makes the *channels* data too; `ArgoErddapSource` (Ifremer, the demo's), `BgcArgoSource` (chlorophyll), `IncoisArgoSource` (registered to prove the seam). Also QC and pressure-to-depth. |
| `samudra/sources/osmc.py` | **Moored buoys**, from NOAA's real-time GTS feed. The seam's hardest case: depth not pressure, one row per level, the surface reading in a different column, no quality flags at all. Four of the nine buoys are India's own OMNI network. |
| `samudra/sources/copernicus.py` | **Current vectors, as numbers.** Copernicus Marine's near-real-time analysis at 1/12 degree, landed on the model's own axes by nearest node - never by averaging, which would flatten a jet two degrees wide. Needs stored credentials at bake time and nothing at demo time. ADR 0013, which supersedes 0011. |
| `samudra/sources/glider.py` | **The glider archive PS 26067 names.** Parses the EGO GDAC directory index by its own column header, scans it against a region, and returns a *finding* alongside whatever casts it found. Over this bake's window it correctly returns nothing, and says why. |
| `samudra/sources/netcdf.py` | **A NetCDF file a visitor hands us**, behind the same protocol as every provider. Sniffs the CF axes - `axis`, then `standard_name`, then units, then the name - and **refuses rather than guesses**: a missing longitude, a sigma coordinate, an ensemble dimension and a region elsewhere in the world all raise `NetcdfAxisError` naming what was wrong. A bare `x` is deliberately not enough to be a longitude. |
| `samudra/sources/woa.py` | **The World Ocean Atlas 2023 1991-2020 normal**, over OPeNDAP, anonymously. `fetch_grid` takes a **month** rather than an instant, because a climatology has no year - that difference is what makes it a baseline rather than a value. Turns WOA's 9.96921e36 fill into NaN, which matters: differenced against a real analysis it would be an anomaly of 1e36. |
| `samudra/hazard.py` | **The five disaster-management Fields.** D26, cyclone heat potential, mixed layer depth, isothermal layer depth, barrier layer thickness. All from temperature, salinity and the TEOS-10 density already in hand. Read the docstring for the vertical-resolution limit every threshold crossing inherits. ADR 0014. |
| `samudra/grid.py` | `Grid` - model data on its native axes. **Scientific truth.** `column_at()` does bilinear interpolation that refuses to blend across land. |
| `samudra/volume.py` | `encode_volume()` - Grid to 4 bytes per voxel: value, coverage, gradient, spare. Read the module docstring before touching it. |
| `samudra/depth_warp.py` | `DepthWarp` - maps INCOIS's 24 uneven depth levels onto an even GPU axis. |
| `samudra/collocation.py` | `collocate()` - pairs a Profile against the model at its exact position. The scientific core. `choose_cast()` decides *which* cast the baked comparison uses: the newest that actually compares against something. |
| `samudra/drift.py` | **Where a thing in the water would go**, according to the analysed current and nothing else. A midpoint integrator over the Copernicus vectors, bilinear in space and refusing to blend across land, linear in time between the ten-day analyses, nearest in depth. `track_against_drift` is the half that matters: an Argo Track is measured drift at the parking depth, so the prediction arrives with its own score. Read the caveat at the top before writing any sentence about it. ADR 0015. |
| `samudra/residuals.py` | **Where the model most disagrees with the instruments.** Ranks every collocated instrument on its RMS residual as a fraction of the Field's own range - which is the only form in which a degC and a PSU can share one list - and bins them onto a 5 degree map, refusing to draw a cell with fewer than three instruments behind it. Nothing here fetches, models or predicts: it is arithmetic over numbers `collocate()` already produced. |
| `samudra/section.py` | **The vertical section**: a great-circle line cut through the Grid, plus the casts within a corridor of it. The distance axis and the behaviour at a coast are the two things that produce a beautiful and false picture if they are wrong, so both have hand-computable cases. |
| `samudra/climatology.py` | **Departure from a real 1991-2020 normal.** Interpolates the atlas onto the model's Levels, refuses to hold the last value down below 1500 m, and raises `AxisMismatch` rather than regridding if the two ever stop sharing node centres. ADR 0016. |
| `samudra/coverage.py` | **Observation Coverage.** Counts Argo *casts* whose dive passed through each slab, in a circular neighbourhood. The docstring records the two rules this replaced and the measurements that forced each change. |
| `samudra/density.py` | **Density.** TEOS-10 sigma-theta from temperature, salinity and pressure. Also `profile_density()`, the observed side of the density Collocation. |
| `samudra/anomaly.py` | **Temperature Anomaly**, and the **Anomaly Features** found in it. Departure from the per-cell mean, the symmetric encoding range a diverging palette needs, and `find_anomaly_features()`. Warm and cool are labelled separately; the docstring says why. |
| `samudra/thermocline.py` | `isotherm_depth()` and `swept_through()`. Where the 20 degC line sits, and whether it moved through a body of water - which is what lets an Anomaly Feature say why it is there. |
| `samudra/palettes.py` | cmocean palettes as 256-entry lookup tables, one per Field. `banded_table()` for Observation Coverage. |
| `samudra/tls.py` | Supplies the intermediate certificate INCOIS's server omits. Do not replace with `verify=False`. |
| `scripts/collect_tests.py` | **What `provenance.html` says about the test suite**, from pytest's own collector and each module's own docstring. That page's whole claim is that its figures are live; the test ones were hand-written and said 67 passed across 11 modules against a real 377 across 25. Run it after adding or removing a test. |
| `scripts/collect_facts.py` | **Every figure the SIH deck may use, read off the build**, into `ppt/FACTS.md`. `DECK.md` has opened with *do not adjust a number by arithmetic* for three rounds and then carried forty figures typed in by hand; two of them were wrong. This gives that warning somewhere to point. Run it after a bake and diff the file: a figure that moved shows up as a line. It does **not** edit the deck, because a figure moving sometimes means a sentence has to be rewritten rather than a digit swapped. |
| `tests/` | One file per module under test. `test_dap.py` and `test_wms.py` cover `api/`, because that is where the science is served rather than rendered. |
