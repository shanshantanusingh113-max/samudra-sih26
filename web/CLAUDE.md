# `web/` - React + TypeScript + Three.js. One WebGL scene for globe and volume.

See the root [`CLAUDE.md`](../CLAUDE.md) for the rules that govern this code, and
[`CONTEXT.md`](../CONTEXT.md) for the vocabulary.

| File | What it does |
| --- | --- |
| `index.html` | **The landing page.** One file, no build step, no external request: tokens for both themes, a full-bleed hero on a chrome-free render, a snapping rail of 14 feature cards that each open one shared `<dialog>` from `data-` attributes, a scroll-progress hairline, staggered reveals, and every figure on the page fetched live from the same manifest the platform draws. The shell is 1320 px and the hero, the rail and the closing panel run full bleed. |
| `provenance.html` | Data provenance. Every figure read live from the baked manifest; nothing hardcoded. |
| `requirements.html` | **Requirement coverage.** Every clause of PS 26067 word for word, the measured figure read live from the manifest, and a link that opens `app.html` with the control that answers it already set. Shares provenance's shell, generated from it, so the design system cannot fork. |
| `app.html` | The application entry. Loads `public/fonts.css` - **not** Google Fonts - and mounts `src/main.tsx`. |
| `vite.config.ts` | Multi-page build: `landing`, `app`, `provenance`, `requirements`. `base: "./"` so it works under a sub-path. |
| `src/App.tsx` | Orchestration: loads data, builds the scene, pushes view state, runs the dive and playback, handles clicks. `applyDeepLink()` reads the query string, so the requirements page can link straight to the control that answers a clause - validated against the manifest, never trusted. |
| `src/store.ts` | Zustand store. Every control's value, plus `touched` (which control the guide explains) and `openGroups` (which panel sections are expanded). `selectField()` is the one place a Variable switch applies its Field's render hints, and it falls back to `DEFAULT_EMPHASIS`/`DEFAULT_OPACITY` rather than leaving the last Field's behind. `reportingByKind()` is what any sentence counting instruments must use. |
| `src/types.ts` | Shapes of the baked JSON. Keep in step with `bake.py`. |
| `src/guide.ts` | **Plain-language explanation of every control.** Edit here to change what the guide panel says. One sentence of definition, then `means` and `look` as **bullets** - max 4, max 2 lines each - because prose blocks of 40 to 70 words are not read mid-demo. Every figure keeps its unit; only words get cut. Measured over the **43** entries by `probe-guide.mjs`, which renders each one and counts what reaches the screen: a median **113 words** on the panel, longest 150, no list over 4 bullets and no bullet over 20 words. **A measured figure is a `{token}`**, filled by `guideFigures()` from the manifest, and a token with nothing behind it takes its bullet off the panel rather than printing a number from a bake that is gone. |
| `src/floatTime.ts` | `positionAt()` / `trackUpTo()` - where a float was at a given moment. The window it uses is the bake's, read from the manifest. |
| `src/agreement.ts` | **How close is close.** The two fractions of a Field's own range at which the model stops agreeing with an instrument, and the position along the diverging palette a signed bias earns. Read by the Collocation verdict *and* by the bias map, so the list cannot call a float the worst in the basin while its own panel says "Close agreement". |
| `src/drift.ts` | The drift integrator **in the browser**, so a dropped pin works with the network unplugged and on the static deployment where there is no API. This is the project's one deliberate second implementation of a piece of science, and it is the *checked* kind: `pipeline/samudra/drift.py` is the tested one, and `probe-drift.mjs` runs this module from the baked start points and fails if the two disagree by more than 2 km. Measured: median 0.331 km, worst 1.573 km over 101 days. |
| `src/section.ts` | The vertical section, **cut in the browser** from the float32 Grid shipped in `public/data/grids/`, so it works offline and on the static deployment. Masked corners are refused **per Level, not per column** - refusing the column blanked the water above a shallow sea floor, measured at 142 of 1,464 cells before it was fixed. Checked against `/api/section` by `probe-section.mjs`. |
| `src/palette.ts` | The display lift applied to cmocean palettes, **per theme**. Applied here so the colourbar and the water agree. Also `colourOf`, `surfacePixels` and `biasColour`, which colour the Fields that are not Volumes and the bias map's markers on the CPU - through the same two functions the colourbar uses, so a Sheet, a marker and their legends cannot disagree. |
| `src/surface.ts` | **The Sheet and the Drape's lattice, resampled once.** Bilinear on the *values* before anything is coloured - blurring colours would interpolate through the palette - and it returns a coverage fraction per cell, which is the alpha ramp that turned the 110 km coast from a cliff into a fade. Both render paths call it, so they cannot disagree about where the coast is. |
| `src/transfer.ts` | **The log/linear Scale, in one place**, plus the two questions that decide where it and the isosurface may act: `supportsLog` (a real zero, a gradient to bend, never negative) and `isDiverging` (a meaningful midpoint, so two isosurface skins and no log). A TypeScript function and the identical GLSL as a string; the shader inlines the string and the colourbar samples the function. There is deliberately no second copy - one is exactly what got this feature cut the first time. |
| `src/data/upload.ts` | **The only place in the frontend that talks to a server**, and it only ever does when a user drops a NetCDF file. Posts the raw bytes, carries the refusal back with the axis it names, and maps this platform's twelve Timesteps onto the file's own instants. `API_BASE` is `VITE_API_BASE` or localhost:8000. |
| `src/data/load.ts` | Fetches the manifest, floats, collocations and volumes; builds GPU textures. |
| `src/scene/OceanScene.ts` | The largest file. Renderer, camera, all geometry, picking, the `ORDER` draw-order table, `debug()`. |
| `src/scene/volumeShader.ts` | The ray-marching GLSL. Transfer function, depth gate, isosurface, gradient emphasis, log scale. |
| `src/scene/fieldShaders.ts` | The two render types that are **not** a ray march: the Sheet a depth Field sits on, and the current arrows. Both take their colour per vertex from the CPU, so neither shader knows a unit. Note the comment about `flat` - it is a reserved GLSL word and cost a silent failure. |
| `src/scene/earthShader.ts` | The globe-to-map morph, and the sea-surface field. |
| `src/scene/geography.ts` | Coordinate mapping and the depth-axis inversion. One place decides where things go. |
| `src/scene/morph.ts` | The morph in TypeScript, for picking. Must match `earthShader.ts`. |
| `src/ui/Controls.tsx` | Left panel. **Independent collapsible groups** - opening one leaves the rest alone, and a group is open when its `openGroups` entry is `=== true`, never when it is absent - with the four general Field Groups as a **tab strip** and Hazard behind the **cyclone mode** switch above it. Fourteen buttons under five headings was about 640 px; it is now one row of tabs and 1 to 5 buttons. Re-measured at 1366x768, where the panel starts 74 px down and has **678 px**: all closed **408 px**, Variable alone **527 px**, Variable and Colourbar **722 px**, everything open **2,664 px** - so two groups open now scrolls, and the figures this line used to carry were stale. The panel says *what* and *how much*; the guide panel says *why*, so a paragraph here that explains rather than reports belongs there instead. Every slider carries a `guide` key and an `aria-label`. No palette chooser; each Field carries its own - ADR 0010. |
| `src/ui/ProfilePanel.tsx` | The comparison: chart, verdict, statistics. |
| `src/ui/GuidePanel.tsx` | The right-hand explanation panel. Yields to the Collocation and Anomaly Feature panels. |
| `src/ui/AnomalyPanel.tsx` | What one Anomaly Feature is, in words, and the one control that lets you *see* it: "Show only this body of water" clips the Volume to the Feature's own box. Every sentence driven by a number the bake measured, and **as bullets, to the guide panel's own rule** - measured across all nine Features in a 348 px column, the four labelled blocks are a median **86 words** against the 243 the whole panel used to carry. |
| `src/ui/SectionPanel.tsx` | The section figure. Depth **linear in metres**, not the Depth Warp - the warp is for a GPU's texture axis and this is a chart somebody measures off. Colour through `colourOf`, the same function the colourbar uses. A gap is drawn as a gap. |
| `src/ui/Chrome.tsx` | Top bar, dive button, attribution, and the three things the console offers a first-time visitor: copy this view as a link, **Show me around**, and **Explore**. |
| `src/ui/Timeline.tsx` | Playback and the time slider. |
| `src/ui/DepthRuler.tsx` | Depth labels down the flank of the volume, placed beside the control panel by measuring it - **width, not presence**, because a hidden panel still has a rect and it is all zeros. On the exhibition screen each figure gains its landmark from `DEPTH_LANDMARKS`. |
| `src/ui/MapKey.tsx` | The key naming floats, moored buoys, tracks, currents and coastlines. It **swaps** for the bias map's three-ended scale when that mode is on, because the dots stop meaning "an instrument" and start meaning "how wrong the analysis was here", and a marker whose meaning changed under an unchanged legend is exactly what got the log scale cut once. In that mode it also says **where** the dots are - at the cast each comparison was taken from, not at the date on screen - because turning the mode on both moves every marker and adds the ones that had not surfaced recently, and two silent changes at once read as a bug. It **folds**, remembered per browser: measured, 330 x 265 px open against 135 x 34 px shut, which is the difference between a legend and a box sitting on the water. |
| `src/ui/Tour.tsx` | **The guided tour: 21 steps in 6 chapters, covering every one of the 43 explained controls.** Each step drives the scene, opens the group the control lives in, and opens its guide entry - so the card at the bottom says *why you would go here* and the panel on the right says what the control does, in `guide.ts`'s own words. `covers` on each step is what `probe-tour.mjs` checks against `GUIDE`. Every step is a store change; touching any control ends it. |
| `src/particles.ts` | **The current flow as moving dots.** A population of 2,400 with a 20-segment fading trail, advected through **one** frozen analysis at the chosen Level. Its step rule and its sampler are `drift.ts`'s, so the animation runs the integrator whose error is published; `probe-particles.mjs` fails if the two ever disagree. Not a trajectory, not three-dimensional, and never finer than the 1 degree Grid. ADR 0017. |
| `src/explore.ts` | **The platform as eight questions**, for the audiences PS 26067 names and the console does not serve. Each is a preset over controls that already exist, and each carries the caveat its simplification costs. Also `trueScale()`, which tweens the exaggeration from 1800x to 1x and back, and `DEPTH_LANDMARKS`. |
| `src/deeplink.ts` | **The inverse of `applyDeepLink`**: the view on screen written back into a URL, and copied to the clipboard. Only what the reader changed goes in, compared against the store's own initial state rather than against a second list of literals. |
| `src/ui/Explore.tsx` | The Explore surface and the exhibition screen behind it. `?kiosk=1` hides the panels, scales the type, plays the questions on a loop and resets 60 s after the last input. Escape leaves. |
| `src/styles.css` | All styling, plus the motion system. Design tokens are at the top. |
| `capture.mjs` | **The screenshot harness, and the only thing that writes into `docs/images/`, `web/public/images/` and `ppt/images/`.** A capture fills `shots/` (scratch, gitignored); `--ingest` promotes those into `assets/screenshots/<theme>/`, which is the one committed copy of every picture, named by what it shows; `--publish` fills the three document folders from there. `WANTS_THEME` decides which theme each document gets - light for the README and the deck, dark for the landing page - with a per-entry override for the exhibition screen, which is dark in all three. Publishing the wrong theme is silent and total and has happened. |
| `probe-landing.mjs` | **The landing page, measured.** Every picture it names exists in `web/public/images/` *and* decodes in the browser out of `web/dist/`, which are two different copies and two different ways to lose one; no request leaves the build; the number word in the features heading equals the number of cards under it; and every hero text block clears 3:1 against the frame with the hero's own words taken away, in both themes at 1600 and 1280 px. Measured: headline 6.49 and 6.15, accent 3.46 and 3.50, light and dark identical to two decimals. |
| `probe-requirements.mjs` | Checks `requirements.html` against the build it describes: no unfilled figure, no external request, and every deep link followed and the control it promised **actually checked**. The expectation is derived from the `href` itself - every query parameter is looked up in `PROMISES` and asserted against the store the link landed in - so a link that grows a parameter this probe has never seen fails rather than passing quietly. It printed all of that and asserted none of it for a round, which is how two links labelled "Open a float comparison" went on opening the guided tour. Set `PREVIEW_URL` if the preview is not on 4173. |
| `probe-controls.mjs` | **Every Field against the two controls whose meaning changes with the Field.** Six rules, checked rather than eyeballed: a Field that forbids an isosurface is not drawing one, the control is on screen only where it can act, a diverging Field gets two skins and a `±` readout, and the log toggle appears only where the range starts at zero and the palette has a gradient to bend. It also fails when a Field never reached the screen at all, because six rules hold vacuously over a Field that threw on the way in. |
| `probe-bias.mjs` | **The bias map, measured.** A frame pair that differs only by the `uBiasMode` uniform; every marker's tint checked against the colour `palette.ts` computes from the shipped `residuals.json`; and a Field with no comparison left carrying none. |
| `probe-guide.mjs` | **Every control has an explanation, and every figure in one came from the bake.** Reads the group ids the panel actually renders and asks `GUIDE` for each - it found three with no entry at all - then renders every entry and fails on an unfilled `{token}`, on a list over four bullets and on a bullet over about two lines. The rule was written in two places and checked in none. |
| `probe-particles.mjs` | **The moving flow, measured.** A particle and a drift pin from the same start point over the same elapsed ocean time end **0.002 km apart after 724 km**; the layer covers **1.8% to 2.5%** of the frame against a 0.001% baseline with it hidden - a range, because the population is seeded with `Math.random()` and the probe asserts a floor rather than a figure; **0 of 2,400** dots sit where the field has no current; and exactly one of the two styles is ever on screen. |
| `probe-tour.mjs` | **Every control is on the tour, and the tour survives it.** Coverage comes from the shipped `tourCoverage()`, not from a list in the probe. Also fails on a step that ends the tour, and on a step that changes nothing the scene reads. 21 steps, 6 chapters, 43 of 43 entries. |
| `probe-outreach.mjs` | **Explore, kiosk and the copied link.** Each question is run and the state it lands on checked against what its card promised; every question that simplifies a limit must carry a caveat; kiosk is checked to leave nothing of the console on screen, to advance on its own after 22 s of nobody touching it, and to exit on Escape; and a written link is round-tripped through `applyDeepLink` in a fresh page. |
| `probe-pixels.mjs` | Not a probe: a PNG decoder in 80 lines of `node:zlib`, so a probe can measure a **picture** rather than a compressed file. `CLAUDE.md` forbids diffing PNG bytes for a magnitude and this is what makes obeying it free. |
| `probe-upload.mjs` | **The NetCDF drop, end to end.** Hands the panel's own file input a real file, then checks the axes were read right, the variable became a Field under the `yours` tab, the picture actually changed (measured: 59.12% of the frame), the GPU texture is 56 x 36 x 48, and a sigma-coordinate file is refused by name with nothing drawn. Needs the API running; it is the only probe that does, because it is the only feature that does. |
| `probe-section.mjs` | **The browser's section against the pipeline's**, value by value along the same line. Measured: 1,102 values, worst gap 5.07e-5 degC, no disagreement about where there is ocean, distance axes within 0.005 km. Also checks a line running onto the Indian coast is part water and part gap, and that drawing one puts ink on the canvas. Needs the API. |
| `probe-drift.mjs` | **The browser's drift integrator against the pipeline's**, from the same start points, in kilometres. Also: a dropped pin draws a line (frame pair on `visible`, nothing else moved), the selected float's predicted track is the *baked* polyline vertex for vertex, and a pin outside the current field refuses instead of drawing a straight line to nowhere. |
| `probe-hazard.mjs` | Measures the three new render types rather than looking at them: diffs each Field's frame against the same frame with its geometry hidden, and projects the file's deepest and shallowest cells to check the Sheet lands in the right order. It found the `flat` bug on its first run. Also fails on an isosurface still drawn under a Field that forbids one, and on the log scale bending the water without the colourbar - which needs the Colourbar group **opened first**, because `.colourbar` is not in the DOM while it is shut and the check read `null` for a round. |
| `probe-isolate.mjs` | **"Show only this body of water", measured two ways.** The clip box is read back off `uFocusMin`/`uFocusMax`, converted to degrees and compared with the Feature's own - which is what catches the north-referenced mirror, because a pixel test cannot: this camera compresses 35 degrees of latitude into about 3 px a degree, so the 8-degree bug moved the water 27 px. Then the water that survived the clip is diffed against a volume-off frame and its **centroid** checked against the Feature's projected centre, bounded to the band between the panels because the right-hand panel fades in and was 83% of the differing pixels. |
